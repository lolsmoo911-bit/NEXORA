# Security Policy

## Project Status

NEXORA is a **testnet/development** project. It has **not** completed an independent security audit and must not be treated as production-ready.

## Supported Scope

- Development and local/testnet verification workflows only
- No production deployments, no real-value operations, no mainnet guarantees

## Reporting a Vulnerability

Please do **not** open public issues for suspected security vulnerabilities.

Report privately to the maintainers with:

- A clear description of the issue and affected components
- Reproduction steps or proof-of-concept (if available)
- Impact assessment and any suggested mitigations

We will review reports on a best-effort basis and coordinate a fix/disclosure process appropriate to project status.

## Security Notes

- Validator/test keys in development contexts may be public/test-only and must never be used for real assets.
- Passing tests do not constitute a security audit or formal verification.
