# NEXORA — الرؤية والنطاق التقني (Phase 1 Baseline)

> **الحالة:** Baseline محلي/وثائقي (بدون تكلفة، بدون نشر عام)  
> **المرجع:** [ZERO-COST-DEV-PLAN.md](./ZERO-COST-DEV-PLAN.md) — المرحلة 1

## 1. الرؤية

بناء **منصة + شبكة بلوكشين (EVM-compatible)** تُمكّن المستخدمين (في مراحل مستقبلية وبعد استيفاء المتطلبات القانونية والتشغيلية) من:
- التداول والمضاربة على أصول رقمية تمثيلية.
- الامتلاك التدريجي لأصول رقمية مرتبطة بأصول حقيقية.

**فئات الأصول المستهدفة (على المدى البعيد):** العملات الورقية (FX)، المعادن، أصول الطاقة، الأسهم، السندات، وصناديق التحوط/الصناديق الاستثمارية.

> **تنبيه:** هذا المستودع اليوم يمثل **أساسًا تقنيًا محليًا/اختباريًا** وليس منصة تداول أو إصدار أصول حقيقية جاهزة للإنتاج.

## 2. الوضع الحالي (Current State)

### ما هو متاح
- **سلسلة Devnet محلية (EVM):** إعداد وتشغيل محلي للتحقق (Chain ID `902024`, denom `anex`).
- **هوية الأصول (AID):** مواصفة وعقود (`AidRegistry`, `AidFactory`) مع اختبارات ونشر/تحقق محلي.
- **عقود اختبارية:** عقود في `source/aid` و`source/contracts` (تشمل تحسينات أمان/منطق مثل chain enforcement، pull refunds، وAssetRegistry المدعوم بالبراهين ضمن النطاق الاختباري).
- **Market Core (حتمي):** نواة تسعير/محاكاة في `source/market` (سندات، منحنيات، فروقات ائتمان، FX، سيناريوهات كريبتو، محاكاة، state migration).
- **مكونات مساندة:** سكربتات CI/محلية (`source/ci`)، وخدمات/أدوات في `artifacts/` (مثل API server/faucet في سياق محلي/اختباري).

### ما هو غير متاح
- شبكة عامة/إنتاج، تدقيق أمني مستقل مكتمل، حوكمة وإدارة مفاتيح إنتاجية.
- محرك تداول فعلي للمستخدمين، دفتر أوامر/سيولة إنتاجية، أو تسوية حقيقية.
- أوراكل أسعار حية إنتاجية، وصاية/احتياطي/استرداد فعلي للأصول الحقيقية.
- امتثال قانوني/تنظيمي (KYC/AML، تراخيص، أطر ملكية/مطالبات) وتنفيذ فعلي للملكية التدريجية.

## 3. النطاق المستهدف (بدون تكلفة / محليًا)

### 3.1 داخل النطاق (In Scope - Local/Simulated)
- **تمثيل الأصول:** نماذج بيانات وعقود/واجهات تمثيلية (test-only) لأنواع الأصول المستهدفة.
- **هوية وربط الأصول:** توحيد استخدام AID/AssetRegistry وربط البيانات الوصفية.
- **التسعير والمحاكاة:** استخدام وتوسعة `source/market` مع تغذية أسعار محاكاة (mock feeds).
- **تداول محاكى:** محرك أوامر/مطابقة وخدمات محافظ/مراكز في بيئة محلية.
- **واجهات السيرفر:** APIs محلية للأصول، الأسعار المحاكاة، الأوامر، الصفقات، المحافظ، والتقييم.
- **الفهرسة والمراقبة المحلية:** Indexer وأحداث وسجلات/health checks قابلة للتشغيل محليًا.
- **الأمان الاختباري:** اختبارات وحدة/تكامل/خصائص (properties/fuzz حيث مناسب) ونمذجة تهديدات ضمن النطاق المحلي.

### 3.2 خارج النطاق الحالي (Out of Scope Now)
- نشر عام، RPC عام، بنية تحتية مدفوعة، أو تشغيل مدققين خارجيين.
- بيانات سوق مدفوعة أو أوراكل إنتاجي حقيقي.
- معاملات/قيمة حقيقية، حفظ أصول حقيقية، أو وعود ملكية/استرداد قانونية.
- تكاملات مصرفية/وساطة/حفظ مؤسسي أو تراخيص تنظيمية.

## 4. حالات الاستخدام الأساسية (مستهدفة للتنفيذ المحلي/المحاكاة)

| الحالة | الوصف | نمط التنفيذ (بدون تكلفة) |
|---|---|---|
| تعريف وتمثيل أصل | إنشاء تعريف أصل (نوع، بيانات وصفية، حالة) وربطه بهوية AID | عقود/نماذج محلية + اختبارات |
| تغذية تسعير | توفير أسعار/مؤشرات للأصل | Mock Oracle + بيانات محاكاة |
| إنشاء أمر تداول | وضع أمر شراء/بيع محاكى | Matching engine/API محلي |
| مطابقة وتسوية محاكاة | مطابقة أوامر وتحديث الأرصدة/المراكز افتراضيًا | خدمات سيرفر محلية + سجلات |
| تقييم محفظة | حساب قيمة/تعرض/Metrics أساسية | Market Core + Portfolio service |
| إدارة دورة الحياة | تفعيل/إيقاف/تعليق أصل أو سوق | قواعد حالة في العقود/السيرفر |

## 5. مصفوفة الأصول المستهدفة (تمثيل تقني أولي)

| فئة الأصل | أمثلة | نمط التمثيل المقترح (محلي) | التحدي الخارجي لاحقًا |
|---|---|---|---|
| عملات (FX) | USD, EUR, Gold-pegged pairs | Fungible token/indexed asset + mock feed | بيانات حية، تسوية/ربط مالي |
| معادن | Gold, Silver | Fungible/representational token + mock feed | وصاية، إثبات احتياطي |
| طاقة | Oil, Gas | Representational instrument + mock feed | توحيد العقود المرجعية والبيانات |
| سندات | Govt/Corp bonds | Debt instrument model + pricing via market core | بيانات إصدار/استحقاق/ائتمان حقيقية |
| أسهم | Equities | Representational instrument (simulated) | قيود قانونية/سوقية وحقوق ملكية |
| صناديق | Hedge/Investment funds | NAV-based representational units (simulated) | حوكمة صندوق، تقارير، امتثال |

## 6. افتراضات وقيود

### افتراضات
- التطوير سيتم تدريجيًا وبتحقق محلي قابل لإعادة الإنتاج.
- المخرجات الأولى هي **نماذج أولية تقنية** (specs/contracts/services/tests) وليست منتجًا تجاريًا.

### قيود
- بدون تكلفة: لا بنية تحتية عامة، لا مزودي بيانات مدفوعين، لا تدقيق خارجي.
- الفجوة القانونية/التشغيلية للملكية الحقيقية للأصول تبقى خارج التنفيذ الحالي.
