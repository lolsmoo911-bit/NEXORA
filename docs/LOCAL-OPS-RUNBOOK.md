# Local Ops Runbook (Zero-Cost / Local-Only)

هذا الدليل للتشغيل والمراقبة المحلية لمكونات NEXORA في بيئة تطوير/اختبار بدون بنية تحتية مدفوعة.

## 1. النطاق
- تشغيل محلي فقط (devnet محلي، خدمات/وحدات محاكاة، اختبارات).
- لا نشر عام، لا RPC عام، لا معاملات حقيقية.

## 2. فحوصات أساسية قبل التشغيل
- التحقق من الاعتماديات: `pnpm install`
- التحقق من الأنواع والبناء: `pnpm run typecheck && pnpm run build`
- اختبارات العقود (عند الحاجة): `PATH="/home/runner/workspace/.foundry/versions/foundry-rs/foundry/v1.8.5:$PATH" forge test` داخل `source/contracts`
- اختبارات وحدات JS المستهدفة: `node --test <paths>`

## 3. تشغيل/إيقاف devnet المحلي (عند الحاجة)
- استخدم سكربتات `source/ci/` وتهيئة `source/chain/` حسب البيئة المحلية المتاحة.
- تأكد من إيقاف العملية بعد الانتهاء (مثال: `pkill -f 'evmd start'`).
- تحقق من عدم بقاء عمليات `evmd` قيد التشغيل.

## 4. المراقبة المحلية
- استخدم `source/observability/src/observability.mjs`:
  - `createLogger()` لتسجيل أحداث منظمة (JSON-like entries).
  - `createHealthRegistry()` لتسجيل وتنفيذ فحوصات الصحة (`ok/degraded/down`).
  - `summarizeRuntime()` لملخص الحالة (uptime, counters, health).
- نقاط فحص مقترحة:
  - توفر الخدمات الداخلية (matching, portfolio, pricing, indexer)
  - حداثة الأسعار المحاكاة (fresh/stale)
  - أخطاء التحقق/الصلاحيات/انتقالات الحالة

## 5. استكشاف الأخطاء (محلي)
- **فشل اختبارات:** أعد تشغيل الاختبار المستهدف، افحص المدخلات والحالات الحدّية، وتحقق من عدم وجود تراجع في الوحدات المشتركة.
- **حالة بيانات غير متسقة (محاكاة):** استخدم replay/rebuild (مثل indexer rebuildFrom) للتحقق من الحتمية.
- **مشاكل صلاحيات:** راجع RBAC والأدوار وسجل التدقيق.
- **سعر قديم (stale):** تحقق من `updatedAt` و`isFresh` في تغذية Mock Oracle/السعر المحلي.

## 6. قواعد أمان تشغيلية (محلي)
- لا تستخدم مفاتيح/بيانات حقيقية.
- لا تشغّل نقاط وصول عامة.
- لا تعتبر نتائج الاختبارات المحلية تدقيقًا أمنيًا أو جاهزية إنتاج.
