# Phase 17 — التكامل الشامل والمحاكاة الطرفية (End-to-End Simulation)

> **الحالة:** ✅ مكتملة (محلي/اختباري، بدون تكلفة)  
> **المرجع:** [ZERO-COST-DEV-PLAN.md](./ZERO-COST-DEV-PLAN.md)

## 1. الهدف
التحقق من عمل السيناريو الكامل محليًا عبر تكامل المكونات الأساسية (إصدار أصول، تسعير محاكى، تداول/مطابقة، محافظ، فهرسة، ضوابط) بشكل حتمي وقابل لإعادة الإنتاج.

## 2. النطاق
### داخل النطاق
- اختبار/سيناريو E2E في `source/e2e/test/e2e-simulation.test.mjs` (ومساعدات عند الحاجة).
- سيناريو يغطي:
  - إصدار أصول تمثيلية محاكاة وتفعيلها
  - تغذية أسعار محاكاة
  - إنشاء حسابات وإيداعات
  - أوامر ومطابقة وتنفيذ صفقات
  - تحديث المحافظ والمراكز
  - تقييم/تسعير عبر market/pricing
  - فهرسة أحداث وsnapshot/replay consistency
- توثيق نتائج التشغيل.

### خارج النطاق
- تحميل/أداء إنتاجي
- شبكات عامة أو بيانات حية

## 3. خطة التنفيذ
1. إنشاء سيناريو E2E واختباراته.
2. تشغيل `node --test source/e2e/test/*.mjs`.
3. التحقق من الحتمية/إعادة البناء حيثما ينطبق.
4. تحديث التقدم والوثائق ودفع التغييرات.

## 5. معيار القبول
- السيناريو الكامل يمر محليًا.
- اللقطات/النتائج متسقة وقابلة لإعادة الإنتاج ضمن نفس المدخلات.


## 6. نتائج التحقق
- تمت إضافة:
  - `source/e2e/test/e2e-simulation.test.mjs`
- سيناريو E2E يغطي:
  - إصدار وتفعيل أصول تمثيلية (issuance + lifecycle)
  - تغذية أسعار محاكاة (بما في ذلك تطبيع feed)
  - حسابات/إيداعات، أوامر، مطابقة، صفقات
  - تطبيق fills على المحافظ وتحديث marks/tPnL
  - تقييم FX عبر pricing service
  - فهرسة أحداث، لقطات، وسلوك idempotency للأحداث المكررة
- تنفيذ الاختبارات:
  - `node --test source/e2e/test/e2e-simulation.test.mjs`
- النتيجة: **1 اختبار ناجح، 0 فشل** (سيناريو شامل محلي).
