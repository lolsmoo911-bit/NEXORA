# Security Hardening Notes (Local/Test Scope)

> **النطاق:** تحسينات صلابة محلية لمكونات NEXORA بدون تكلفة وبدون ادعاء جاهزية إنتاج.  
> **تاريخ baseline:** 2026-11-13 (تحديثات مرحلية خلال Phase 16)

## 1. التهديدات المستهدفة (محليًا)

| المسار | أمثلة تهديد/إساءة استخدام | الضوابط الحالية/المضافة |
|---|---|---|
| التداول (Matching Engine) | مدخلات غير صالحة، معرفات مكررة، كميات/أسعار صفرية أو سالبة، إلغاء غير قانوني | تحقق صارم للمدخلات، رفض التكرار، حالات أمر واضحة، اختبارات حدّية |
| المحافظ (Portfolio) | سحب/شراء بدون رصيد كافٍ، قيم سالبة/NaN، تغيرات حالة غير متسقة | فحوصات رصيد ومدخلات، تحديثات حتمية، اختبارات سيناريوهات short/long وحدّية |
| التسعير/الأوراكل المحاكى | تغذية أسعار قديمة/غير موجودة، قيم غير صالحة | تطبيع feed مع `isFresh/exists`، رفض الأسعار غير الصالحة، اختبارات freshness |
| الصلاحيات (RBAC) | تنفيذ عمليات بدون دور مناسب، مستخدم غير نشط | فحص صلاحيات مركزي، سجل تدقيق، اختبارات رفض/سماح |
| سير العمل/دورة الحياة | انتقالات حالة غير صالحة، تفعيل أصل غير مُتحقق | آلة حالات وانتقالات مسموحة فقط، validation gates، اختبارات رفض الانتقال |
| الفهرسة | ازدواجية أحداث، replay غير متسق | idempotency عبر event id، rebuild/replay، اختبارات تكرار وإعادة بناء |

## 2. إجراءات Hardening المنفذة في هذه المرحلة
- إضافة اختبارات خصومية/حدّية إضافية (abuse cases) لوحدات `exchange`, `portfolio`, `api`, `auth`, `indexer`, `workflows`, `controls`.
- التحقق من أن مسارات الرفض (invalid input / unauthorized / invalid transition) تُعيد أخطاء واضحة ومتوقعة.
- الحفاظ على الحتمية (determinism) في المسارات المحاكاة الأساسية.

## 3. ضوابط موصى بها للاستمرار (محليًا)
- توسيع اختبارات property/invariant للعمليات المركبة (مطابقة + محافظ + فهرسة).
- إضافة حدود منطقية (limits/rate-like guards) في طبقات API عند الدمج مع HTTP.
- توحيد رموز/أنواع الأخطاء عبر الخدمات لتسهيل المراقبة والتكامل.
- توثيق افتراضات الثقة لكل وحدة (trust boundaries) بشكل صريح.

## 4. قيود متبقية (خارج نطاق بدون تكلفة)
- لا يوجد تدقيق أمني مستقل أو مراجعة خارجية.
- لا توجد حماية إنتاجية ضد خصوم على شبكة عامة (MEV، RPC abuse، DoS موزع).
- لا توجد حوكمة/إدارة مفاتيح/استجابة حوادث إنتاجية.
- تغذية البيانات والأوراكل محاكاة وليست مصادر إنتاج موثوقة.

> **ملاحظة:** نجاح الاختبارات المحلية يدل على صحة سلوك ضمن السيناريوهات المغطاة، ولا يُعد إثباتًا أمنيًا شاملاً.
